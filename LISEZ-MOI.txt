LECTEUR MUSICXML v28 — CORRECTION MIDI IPAD / CASIO
====================================================
La connexion MIDI est tentée automatiquement à l’ouverture, avec un bouton de
reconnexion disponible. Le lecteur essaie d’abord Web MIDI avec SysEx activé,
réessaie sans SysEx si nécessaire et recherche un périphérique pendant environ
15 secondes s’il n’est pas immédiatement visible. Le cache hors ligne a été
renouvelé afin que cette correction soit téléchargée depuis GitHub Pages.
Si le son reste bloqué par iPadOS, touchez une fois l’interface puis rejouez.

Ce lecteur dessine la partition a partir du MusicXML deja prepare par le
convertisseur. Il ne lit pas le PDF et ne controle pas la reconnaissance.
Le son, les reprises, les mesures, les boucles et le curseur utilisent la meme
chronologie musicale. Un MIDI separe n'est plus necessaire a la lecture.

SUR LE PC
---------
Extraire le ZIP entier puis double-cliquer sur lancer.cmd.
Un serveur statique local ouvre le lecteur (ports 8776 a 8795).
Il n'installe rien et ne demande pas les droits administrateur.
Le Python deja present sur ce PC est utilise. Sinon installer Python 3.
Ne pas ouvrir index.html avec file:// : les modules ont besoin de HTTP/HTTPS.

SUR GITHUB / IPAD
----------------
Publier TOUT le contenu de ce dossier dans GitHub Pages. Conserver assets,
partitions, library.json et les chemins relatifs. Aucun serveur Python,
Audiveris, compte ou cle API n'est necessaire sur GitHub ou sur l'iPad.
Ouvrir l'URL HTTPS du site dans votre navigateur iPad prenant en charge Web MIDI.
La premiere ouverture met les fichiers du lecteur et la bibliotheque en cache.
Le son commence apres une action (Lire, note ou clavier), comme l'exige iOS.
Le fonctionnement hors ligne depend du maintien du stockage par le navigateur.

MORCEAUX
--------
Ouvrir accepte .musicxml, .xml et .mxl, avec plusieurs fichiers a la fois.
Les fichiers ouverts ainsi restent sur cet appareil (IndexedDB). Ils ne sont
pas envoyes sur GitHub. Pour les publier, utiliser ajouter-partition.cmd :
choisir ajouter ou retirer, puis un seul fichier du morceau. Si vous choisissez
le PDF ou MIDI, le script cherche le MusicXML de meme nom dans le meme dossier.
Seul le MusicXML est copie. Le cache se met a jour automatiquement.
Le retrait du catalogue conserve le fichier original dans partitions/.

UTILISATION
-----------
- Lire : lecture/pause ; Debut : premiere note et premiers systemes.
- Deux systemes complets sont affiches, puis les deux suivants.
- Cliquez sur une note ou utilisez les fleches pour vous y placer avec son.
- Espace : lire/pause. Fleches gauche/droite : note. Haut/bas : tempo +/-5 BPM.
- Tempo : indication MusicXML, 120 BPM si elle est absente. Minimum 5 BPM.
- Boucle : mesures Debut/Fin, Activer. Pause 1 a 10 secondes. Quitter annule.
- Un numero entre parentheses designe un passage repete de la meme mesure.
- Attendre la note : appuyer sur Lire, puis jouer toutes les notes indiquees
  pour avancer ; une note incorrecte ne fait pas avancer le curseur.
- Connecter le Casio : lire les notes MIDI entrantes. Le piano virtuel reste
  visible. Le bouton Clavier permet de masquer/afficher le piano a volonte.
- FR/EN : texte et noms des notes. Jour/Nuit : apparence de l'interface.

FICHIERS EXISTANTS
-----------------
Gravity Falls et Swan Lake sont des copies de vos anciens MusicXML, pas de
nouvelles conversions verifiees. Le MusicXML Gravity Falls ne contient pas
l'indication 160 BPM visible dans son ancien PDF et comporte des incoherences
d'encodage d'accords. Ce lecteur reproduit les donnees qu'il peut interpreter.
Ces points sont a traiter dans le convertisseur selon l'architecture convenue.

MOTEUR ET LIMITES
----------------
Gravure et chronologie : Verovio 6.3.0, inclus localement. Son : synthese Web Audio.
La mise en page est recalculee : elle ne reproduit pas la pagination du PDF.
La prise en charge des signes musicaux et reprises est celle de Verovio.
Les nuances fines et le pedalage ne sont pas simules par ce piano synthetique.
Les changements de tempo suivent la chronologie fournie par Verovio (aux
frontieres de mesures). Aucun controle de justesse acoustique par micro.
Web MIDI depend du navigateur et de la connexion USB/Bluetooth disponible.

Les versions v25 et anterieures sont conservees separement.
